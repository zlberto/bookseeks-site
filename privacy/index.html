Bookseeks privacy policy

Last updated: October 30, 2026

Bookseeks is a browser extension published by DEFENDOP S.R.L. ("we"). It syncs your bookmarks with a private GitHub repository that you own.

What Bookseeks handles

  • Your bookmarks: the titles, addresses and folders in your Bookmarks bar and Other bookmarks.
  • Your GitHub token: a fine-grained personal access token that you create and enter yourself.
  • Your sync settings: the repository and branch to sync with, whether automatic sync is on, and a copy of your bookmarks from the last sync, which is used to merge changes.

Where it goes

  • Bookseeks sends your bookmarks only to the GitHub repository you choose, through GitHub's API (api.github.com), using your token. GitHub's own privacy policy applies to what you store there.
  • Your token and settings are stored only in your browser's local extension storage. They are never sent anywhere except to GitHub, to authorize the requests above.
  • We do not run any server for Bookseeks. We do not collect, receive, store, sell or share any of your data, and Bookseeks contains no analytics or tracking.

Your control

  • You can see and change everything Bookseeks syncs in your own GitHub repository.
  • Removing the extension deletes the token and settings from your browser. Deleting the repository or revoking the token on GitHub stops all access.
